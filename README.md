# Frédéric & William — Charpente Couverture Guadeloupe

Site vitrine de Frédéric et William, artisans charpentiers couvreurs en Guadeloupe : couverture, charpente, étanchéité, nettoyage, peinture de toiture et projets bois.

Site statique en une page (`index.html` + `images/`), sans dépendance ni étape de build.

## Voir en local

```bash
python3 -m http.server 8000
```

Puis ouvrir http://localhost:8000.
